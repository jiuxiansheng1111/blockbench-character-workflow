# 方块角色造型规则

## 脸型与五官

- 主脸用连续体面，浅下颌过渡；不要把脸颊切成多层皮肤阶梯，也不要整块正方形填满发框。脸部宽高看“露出的皮肤区域”，不是隐藏头壳外包围盒。
- 隐藏额头承托应后退到刘海后方，前额下缘仍与主脸衔接；不能竖直加高皮肤板去堵漏而顶穿斜刘海。
- 眼睛先定上眼线与中心距，再用一小块一小块的浅矩形拼眼白、虹膜、瞳孔、高光和眼角。左右眼使用共同网格和基准高度，避免各自随机上下错位。
- 眼睛深度尽可能统一，只留避免 z-fighting 所需间距；不要把虹膜做成突出脸外的柱体。侧面必须复查。
- 眉毛短、薄、清楚，参考为黑色就用接近黑色；位置和倾斜表现角色表情，不用两条巨大斜杠。贴图眉与几何眉均可，以用户要求和目标格式决定。
- 嘴巴先从一个小浅色矩形开始；只在参考确有需要时增加嘴角或唇色。不要叠多层红唇、做黑洞或凸嘴。
- 鼻子可用微小明暗或省略凸起，按参考判断。用户要求无脖子时，以衣领与头自然衔接，不留柱状颈部。
- 眼睛与眉毛不要因头发遮挡而挤到脸下半部；调整发束遮盖层次，保留识别五官。

## 头发

按顶冠、主刘海、颊侧、太阳穴、耳后、后脑、侧后长发和发饰分组。先做大轮廓和主分缝，再加辅助发束。

每条发束是一条根 → 转折 → 尖端路线；用有厚度的长方体沿路线连接。相邻段保持相近宽度/色相，转折少量重叠藏根。不要把每段都等长等宽，或用随机角度拼散乱碎块。

顶冠沿前额到后脑围出圆润的方块弧，顶点高度渐变；后脑必须覆盖。刘海服从同一分缝和扫向，前后层不应像屋顶瓦片横向排队。两侧发束适度遮住脸颊和太阳穴，仍能读出眼形。长发角色保留披肩、后背长度与发梢方向，不能为方便近脸预览删短主工程。

用少量暗层表示内侧，亮层跟随大受光面；避免整头彩条。发根藏好，发尾逐渐收窄，侧面无突兀直角台阶。头发不把手臂全部吞进一片墙。

## 身体与服装

头部变化后必须再看全身。肩线逐渐下落，上臂和袖子分清；避免肩部厚横梁、细长纸片身体或过窄小裙子。裙摆的横向体积应与上身相配，腿长/裙长以参考和已认可基线为准。

上裙、衬裙和装饰条分层时，白色衬裙起点必须藏在外裙内，避免腰部出现白色尖楔。前短后长的衣摆不能全方向拉成同一高度。鞋与腿共用轴线，脚不悬空。

## 变换与可编辑性

- 骨骼/组命名清楚：head、face、fringe、crown、rear_hair、body、arm_left/right、leg_left/right、skirt 等，沿用现有已正确命名的组。
- 对每个 cube 深拷贝旋转/位置数组；复用数组会在镜像过程中被二次翻转，让裙边或发饰向外刺出。
- X 镜像应同时检查点、局部枢轴、旋转符号与面 UV 方向。不要把世界空间镜像和父级局部镜像重复应用。
- 有父级旋转时，不能只看元素自身 rotation 就断言游戏能接受。记录父子层级、枢轴与坐标单位。
- 保持正尺寸、有限数值和有效纹理索引。小体积特征的“浮空”警告有时是有意浅层结构，但要看真实图才能判断。
