# 参考拆解与本轮简报

## 参考事实表

每人单列：参考来源/使用权限、发色明暗层、眼睛颜色、脸宽/脸高、眼宽/眼距、眉眼距离、口相对眼线的位置、头宽/肩宽、头高/身高、裙宽/肩宽、裙长/腿长、刘海分点、两侧遮脸范围、发梢终点、发饰位置、角色表情与服装轮廓。用可见特征描述，不能凭角色名套通用脸。

量比值时先说明视角：透视、仰俯角和大幅歪头会扭曲测量。正面左右眼在同一基准线上测；明确参考本身的非对称设计。用 Q 版辅助理解分束和配色，不把它的大头大眼比例强加到用户要求的正常比例。小图只能提供粗略证据，放大像素不会生成真实细节。

参考模型的高质量通常来自几处关系：脸是连续体面；五官是规整、浅薄、色块明确的小矩形；头发沿几条主线叠层而非随机插碎片；衣摆与腿的宽度协调。学习这些关系，不复制参考文件。

## 开工前简报模板

1. **本轮基线**：文件名、SHA-256、目标格式；参考有哪些，哪些视角缺失。
2. **用户已认可**：锁定组与外观，禁止顺手改动的内容。
3. **三个主要问题**：例如额头暴露过高、双眼间距过大、后发横向像瓦片；写出参考对应证据。
4. **拟修改参数**：哪组、哪个轴、相对多少，眼白/虹膜/高光怎么排列，发束根/折点/端点怎么动。没有尺寸时先测，不猜统一比例。
5. **轮廓优先顺序**：脸型和眉眼关系稳定后再增加发丝，头身比例稳定后再增加服装装饰。
6. **检查视角与通过条件**：正面五官不散、侧面不凸鼻口、背面不露脑、远景仍识别发型、冻结部件无变化。
7. **本轮不确定项**：推断的背面结构、原图分辨率不足、游戏渲染尚未验证。

## 提示词迭代方式

不要沿用已经被用户否定的审美方向。每轮从“上一轮实际缺陷”写短修改指令：

> 以已认可候选为基线，身体和裙子不变。主脸保持连续表面，眉毛缩短并降低到眼睑上方的参考间距，嘴只保留一块浅色小矩形。眼睛共用浅平面，以规整像素色块组成眼白、上睫、虹膜和高光。刘海根部落在同一冠顶流向，增加颊侧覆盖但保留外眼角可见。保持长发终点，不以碎小方块数量作为精细度。渲染同相机前后图，并核对锁定组。

这只是写法示例，不是所有角色的固定尺寸或万能脸。每个人的眼形、眼距、分缝、刘海缺口和嘴角状态必须单独取证。
